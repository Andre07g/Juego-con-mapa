# CROSS CAVE

Es un juego de texto en consola, estilo rpg, corto y con dos finales

## Descripcion

Cross Cave es un proyecto en Python para practicar manejo de indices, listas y diccionarios  
El movimiento del personaje y los elementos del mapa se realiza a traves de validaciones entre la ubicacion del personaje en la lista y los objetos existentes en ella  
Se elige una clase de personaje entre 4 diferentes, todas con estadisticas distintas  
El objetivo final es vencer al enemigo principal

## Requisitos 

-Python 3  
-Lector de texto que permita ejecutarlo, como Visual Code  

## Instalacion 

-Descargar el zip del repositorio  
-Extraerlo con un programa que lo permita(Winrar-7ZIP)  
-Abrirlo con programa de lectura que posea extension de python  

## Uso del proyecto

-Aumentar la fuente de la terminal entre 18 y 30  
-Presionar solo una tecla por movimiento, para evitar adelantar acciones
